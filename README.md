# Garden Advice App

A simple Python application that provides gardening advice based on the season and plant type.

## Features
- Asks the user for the current season (summer/winter)
- Asks the user for the plant type (flower/vegetable)
- Provides specific advice based on the inputs

## How to Run
1. Make sure you have Python installed.
2. Run the script in your terminal:
   `python garden_advice.py`
